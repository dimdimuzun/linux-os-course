# Книги

Добірка книг для поглиблення знань за темами курсу.

!!! warning "Перевірте відомості про видання"

    Бібліографічні дані наведено за пам'яттю автора курсу, без доступу до каталогів і пошуку. Перш ніж купувати чи рекомендувати книгу студентам, перевірте автора, назву, поточне видання та доступність (деякі книги мають новіші видання; частина доступна безкоштовно онлайн).

## Для початківців

| Книга | Автор | Навіщо читати |
|---|---|---|
| *The Linux Command Line* | William Shotts | Найкращий вступ до командного рядка: навігація, файли, права, процеси, перенаправлення, скрипти. Відповідає модулям 3–8 і 14. Автор поширює книгу безкоштовно на сайті linuxcommand.org |
| *Linux Pocket Guide* | Daniel J. Barrett | Компактний довідник команд за темами, зручно тримати поруч під час практики |
| *Linux Bible* | Christopher Negus | Широкий огляд: встановлення, користувачі, пакети, мережі, служби |

## Як працює Linux і адміністрування

| Книга | Автор | Навіщо читати |
|---|---|---|
| *How Linux Works* | Brian Ward | Пояснює, що відбувається «під капотом»: завантаження, `systemd`, диски й файлові системи, мережі, процеси. Добре доповнює модулі 8, 10, 11, 13 |
| *UNIX and Linux System Administration Handbook* | Evi Nemeth та ін. | Класичний довідник адміністратора: користувачі, сховища, мережі, безпека, резервні копії. Для просунутого рівня й як довідник |

## Як користуватися

1. Починайте з *The Linux Command Line* паралельно з модулями 3–8.
2. Для розуміння процесів завантаження й служб додайте *How Linux Works*.
3. Для теоретичної основи курсу «Операційні системи» використовуйте *Operating Systems: Three Easy Pieces* або університетський підручник.
4. Не замінюйте книгами практику: запускайте приклади в лабораторній VM.
