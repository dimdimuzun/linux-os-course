# Інструменти

Програмні засоби, корисні під час проходження курсу. Для інструментів у Ubuntu наведено команду встановлення (модуль 9). Ставте пакети в навчальній VM і перед масовими змінами створюйте знімок.

!!! note

    Назви пакетів і наявність у репозиторіях можуть відрізнятися залежно від випуску Ubuntu й підключених компонентів (`universe`). Якщо `apt` не знаходить пакет, виконайте `sudo apt update` і перевірте назву командою `apt search --names-only '^назва$'`.

## Навчальне середовище

| Інструмент | Призначення | Примітка |
|---|---|---|
| Ubuntu 24.04 LTS | Основне середовище курсу | Образ ISO з сайту Ubuntu |
| VirtualBox | Віртуальна машина для лабораторних робіт | Режими мережі NAT, Bridged, Host-only (модуль 2); **знімки** перед кожною ЛР |
| WSL, хмарні VM | Альтернативні середовища | Окремі можливості (loop-пристрої, `systemd`, мережа) можуть не працювати так, як описано в курсі |

## Процеси, ресурси й діагностика

| Інструмент | Призначення | Встановлення |
|---|---|---|
| `htop` | Інтерактивний монітор процесів | `sudo apt install htop` |
| `sysstat` (`iostat`, `sar`, `pidstat`) | Статистика процесора, диска | `sudo apt install sysstat` |
| `lsof` | Відкриті файли й сокети | `sudo apt install lsof` |
| `strace` | Трасування системних викликів | `sudo apt install strace` |
| `psmisc` (`fuser`, `pstree`, `killall`) | Допоміжні утиліти для процесів | `sudo apt install psmisc` |
| `smartmontools` | Стан фізичних дисків (SMART) | `sudo apt install smartmontools` |

`strace`, `lsof` і подібні інструменти можуть показувати чутливі дані: застосовуйте їх лише до власних процесів і тестових даних.

## Мережа

| Інструмент | Призначення | Встановлення |
|---|---|---|
| `curl`, `wget` | HTTP-клієнти | `sudo apt install curl wget` |
| `dig`, `nslookup` | DNS-запити | `sudo apt install bind9-dnsutils` |
| `traceroute`, `mtr` | Дослідження маршруту | `sudo apt install traceroute mtr-tiny` |
| `tcpdump` | Захоплення пакетів у консолі | `sudo apt install tcpdump` |
| Wireshark | Графічний аналіз захоплень | `sudo apt install wireshark` |
| `nmap` | Сканування портів | `sudo apt install nmap` |
| `netcat` (`nc`) | Перевірка портів, прості з'єднання | Зазвичай `netcat-openbsd` |

!!! danger

    `nmap`, `tcpdump` і Wireshark використовуйте **лише на власних системах або з письмового дозволу власника мережі**. Сканування й перехоплення чужого трафіку без дозволу можуть бути протиправними. У навчальних завданнях достатньо локального вузла, loopback-інтерфейсу й адрес документації (`192.0.2.0/24`).

## Безпека й журнали

| Інструмент | Призначення | Встановлення |
|---|---|---|
| `ufw` | Керування брандмауером | Входить до Ubuntu (за замовчуванням вимкнений) |
| AppArmor (`aa-status`) | Мандатний контроль доступу | Входить до Ubuntu |
| `fail2ban` | Автоматичне блокування адрес після невдалих входів | `sudo apt install fail2ban` |
| `auditd` | Докладний аудит системних подій | `sudo apt install auditd` |
| `lynis` | Автоматизований аудит захисту з рекомендаціями | `sudo apt install lynis` |
| `logrotate` | Ротація журналів | Входить до системи |
| `journalctl`, `logger` | Читання й запис системного журналу | Входять до `systemd` і `util-linux` |

Перш ніж встановлювати засіб безпеки, прочитайте його документацію: помилкові налаштування `ufw`, `fail2ban` чи SSH можуть заблокувати вам доступ до системи.

## Порада

Не встановлюйте все одразу. Ставте інструмент тоді, коли розумієте, яку проблему він розв'язує, і видаляйте після завершення практики, якщо він більше не потрібен (`sudo apt purge пакет`, `apt -s autoremove` для перегляду).
