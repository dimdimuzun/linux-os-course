# Лабораторна робота №5. Пакети та Systemd

## Тема

**Пакети та Systemd**

## Пов'язані модулі

Модулі 9–10.

## Мета

Закріпити теоретичні знання та сформувати практичні навички роботи з Linux через командний рядок.

## Вимоги

- Ubuntu 24.04 LTS;
- навчальна віртуальна машина;
- користувач із правами `sudo`;
- доступ до термінала.

## Початкова підготовка

```bash
whoami
hostname
uname -a
pwd
```

## Завдання 1. Ознайомлення із середовищем

```bash
id
pwd
ls -la
```

Поясніть призначення кожної команди та інтерпретуйте результат.

## Завдання 2. Практична робота

Виконайте операції відповідно до тем лабораторної роботи та перевірте результат командами діагностики.

```bash
command --help
```

## Завдання 3. Аналіз

Дайте відповіді:

1. Що змінилося в системі після виконання команд?
2. Якими командами можна перевірити результат?
3. Які помилки можливі?
