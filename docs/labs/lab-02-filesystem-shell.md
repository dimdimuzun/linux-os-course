# Лабораторна робота № 2. Файлова система та командна оболонка

## Тема

**Файлова система Linux та командна оболонка Bash. Навігація за ієрархією каталогів, робота з точками монтування, змінними, шаблонами, перенаправленням і конвеєрами.**

## Пов'язані модулі

- Модуль 3. Файлова система.
- Модуль 4. Термінал і командна оболонка Linux.

## Мета

Закріпити теоретичні знання про структуру файлової системи Linux і принципи роботи командної оболонки Bash, сформувати практичні навички навігації файловою системою та використання можливостей оболонки для обробки даних.

Під час виконання лабораторної роботи студент повинен:

- дослідити структуру кореневого каталогу та призначення основних каталогів за стандартом FHS;
- розрізняти абсолютні та відносні шляхи й упевнено переміщатися файловою системою;
- визначати точки монтування, типи файлових систем і розташування каталогів на дисках;
- використовувати змінні оболонки, змінні середовища та `PATH`;
- правильно застосовувати лапки й шаблони імен файлів;
- перенаправляти stdout і stderr та будувати конвеєри команд;
- перевіряти код завершення команд і використовувати оператори `;`, `&&`, `||`;
- сформувати текстовий звіт про файлову систему за допомогою команд оболонки.

## Вимоги

Для виконання лабораторної роботи необхідно мати:

- робоче Linux-середовище з доступом до командного рядка;
- обліковий запис звичайного користувача;
- можливість виконувати команди без адміністративних привілеїв;
- доступ до навчальних матеріалів модулів 3 і 4;
- результати лабораторної роботи № 1 (для порівняння характеристик середовища).

Рекомендоване середовище:

- Ubuntu 24.04 LTS у віртуальній машині;
- термінал Linux з оболонкою Bash.

Допускається використання іншого дистрибутива Linux. Для WSL і контейнерів результати завдання 3 можуть суттєво відрізнятися від наведених у прикладах; такі відмінності необхідно зафіксувати у звіті.

**Важливо:** усі завдання виконуються без `sudo`. Усі файли, які ви створюєте, розміщуються лише у вашому домашньому каталозі, у підкаталозі `~/lab02`.

## Правила виконання роботи

1. Уважно прочитайте умову кожного завдання.
2. Виконуйте команди послідовно, у тому порядку, у якому вони наведені.
3. Аналізуйте результат кожної команди, а не лише копіюйте його.
4. Записуйте отримані результати у звіт.
5. Якщо результат відрізняється від очікуваного, з'ясуйте причину.
6. Перед використанням `>` перевіряйте шлях і назву файла: цей оператор перезаписує вміст.
7. Не змінюйте системні файли та налаштування.
8. Помилки, які виникають, фіксуйте у звіті разом із повідомленням і поясненням причини. Деякі помилки в цій роботі є навмисними й слугують для демонстрації поведінки оболонки.

Усі приклади виведення команд у цій роботі є умовними. Результати у вашому середовищі можуть відрізнятися.

## Початкова підготовка

### 1. Відкрийте термінал і перевірте середовище

Виконайте:

```bash
whoami

ps -p "$$" -o pid=,comm=

```

Запишіть у звіт ім'я користувача, оболонку за замовчуванням і назву поточного процесу оболонки.

### 2. Створіть робочий каталог

Усі файли цієї роботи створюються в каталозі `~/lab02`.

```bash
mkdir -p ~/lab02 && echo "Каталог готовий"
ls -ld ~/lab02
```

Команда `mkdir -p` створює каталог, а за його наявності не повертає помилку. Докладно команди керування каталогами розглядаються в модулі 5; тут достатньо виконати наведені команди.

## Завдання 1. Структура кореневого каталогу та стандарт FHS

**Теорія:** модуль 3, розділи 3.3, 5 і 6.

### Мета

Навчитися досліджувати структуру кореневого каталогу Linux і пов'язувати каталоги з їхнім призначенням за стандартом FHS.

### Порядок виконання

**Крок 1. Перегляньте вміст кореневого каталогу.**

```bash
ls /
ls -l /
```

Зверніть увагу на першу літеру в рядках результату `ls -l`: `d` означає каталог, `l` — символічне посилання.

**Крок 2. Перегляньте відомості про основні каталоги.**

```bash
ls -ld /bin /boot /dev /etc /home /lib /proc /root /run /sbin /sys /tmp /usr /var
```

Деякі каталоги можуть бути відсутніми в конкретному середовищі. Зафіксуйте це у звіті.

**Крок 3. Дослідіть символічні посилання на каталоги.**

```bash
ls -ld /bin /sbin /lib
readlink -f /bin
```

У сучасних дистрибутивах каталоги `/bin`, `/sbin` і `/lib` часто є символічними посиланнями на відповідні підкаталоги в `/usr`.

**Крок 4. Перегляньте вміст кількох каталогів.**

```bash
ls /etc | head -n 10
ls /var
ls /usr
ls /home
```

**Крок 5. Дізнайтеся, у якому каталозі розташовані виконувані файли команд.**

```bash
command -v ls
command -v whoami
command -v bash
```

**Крок 6. Ознайомтеся з довідкою про ієрархію файлової системи.**

```bash
man hier
```

Для виходу натисніть `q`. Якщо сторінка відсутня, зазначте це у звіті та скористайтеся матеріалами модуля 3.

## Завдання 2. Абсолютні та відносні шляхи

**Теорія:** модуль 3, розділ 4.

### Мета

Навчитися переміщатися файловою системою за допомогою абсолютних і відносних шляхів та користуватися спеціальними позначеннями `.`, `..`, `~`, `-`.

### Порядок виконання

**Крок 1. Перейдіть до різних каталогів за абсолютними шляхами.**

```bash
cd /
pwd
cd /var/log
pwd
```

**Крок 2. Перейдіть за відносними шляхами.**

```bash
cd ..
pwd
cd ../etc
pwd
cd /
cd usr/share
pwd
```

Для кожної команди визначте, від якого каталогу відраховується шлях.

**Крок 3. Поверніться до домашнього каталогу та використайте `cd -`.**

```bash
cd ~
pwd
cd /etc
cd -
pwd
echo "$PWD"
echo "$OLDPWD"
```

`cd` без аргументів також повертає до домашнього каталогу. `cd -` переходить до попереднього каталогу, який зберігається у змінній `OLDPWD`.

**Крок 4. Створіть вкладену структуру та перемістіться нею.**

```bash
mkdir -p ~/lab02/paths/level1/level2
cd ~/lab02/paths/level1/level2
pwd
cd ../..
pwd
cd level1
pwd
```

**Крок 5. Проаналізуйте поточний шлях.**

```bash
cd ~/lab02/paths/level1/level2
realpath .
basename "$PWD"
dirname "$PWD"
cd ~
```

## Завдання 3. Точки монтування та файлові системи

**Теорія:** модуль 3, розділи 7–9.

### Мета

Навчитися визначати, які файлові системи підключені до дерева каталогів, і розуміти, що єдине дерево каталогів може об'єднувати кілька пристроїв і віртуальних файлових систем.

### Порядок виконання

**Крок 1. Визначте файлову систему, змонтовану в корені.**

```bash
findmnt /
```

Зафіксуйте джерело (`SOURCE`), точку монтування (`TARGET`), тип файлової системи (`FSTYPE`) і параметри (`OPTIONS`).

**Крок 2. Визначте, на якій файловій системі розташований ваш домашній каталог.**

```bash
findmnt -T ~
df -hT ~
```

Параметр `-T` показує файлову систему, якій належить указаний шлях.

**Крок 3. Перегляньте використання дискового простору.**

```bash
df -hT
```

Знайдіть у результаті корінь `/`, а також точки монтування `/boot`, `/run`, `/dev`, якщо вони є.

**Крок 4. Перегляньте блокові пристрої.**

```bash
lsblk
```

Знайдіть диск або розділ, на якому розташована коренева файлова система.

**Крок 5. Дослідіть віртуальні файлові системи.**

```bash
findmnt /proc
findmnt /sys
findmnt /run
cat /proc/version
ls /proc | head -n 5
```

Каталог `/proc` не зберігає звичайні файли на диску: його вміст формує ядро під час читання.

**Крок 6. Перегляньте початок списку всіх змонтованих файлових систем.**

```bash
findmnt | head -n 15
```

**Увага:** у цій роботі **не виконуйте** команд `mount`, `umount` і запису в `/etc/fstab`. Вони змінюють конфігурацію системи.

### Результати

Заповніть таблицю.

| № | Точка монтування | Джерело | Тип файлової системи | Команда |
|---|---|---|---|---|
| 1 | `/` | | | `findmnt /` |
| 2 | Каталог, що містить `~` | | | `findmnt -T ~` |
| 3 | `/proc` | | | `findmnt /proc` |
| 4 | `/sys` | | | `findmnt /sys` |
| 5 | `/run` | | | `findmnt /run` |

Додатково запишіть:

- загальний розмір кореневої файлової системи та відсоток використання за `df -hT`;
- назву диска або розділу, на якому розташована коренева файлова система, за `lsblk`;
- типи файлових систем, які трапилися у виведенні `findmnt | head -n 15`, і перелік тих із них, що є віртуальними.

### Запитання для аналізу

1. Що таке точка монтування?
2. Чим монтування відрізняється від підходу з літерами дисків, який використовується в Windows?

## Завдання 5. Шаблони імен файлів

**Теорія:** модуль 4, розділ 7.3.

### Мета

Навчитися використовувати шаблони `*`, `?`, `[...]` для вибору файлів і розуміти, що розгортання шаблонів виконує оболонка до запуску команди.

### Порядок виконання

**Крок 1. Підготуйте тестові файли.**

```bash
mkdir -p ~/lab02/patterns
cd ~/lab02/patterns
touch file1.txt file2.txt file3.log report1.txt report2.txt report10.txt notes.md
ls
```

Команда `touch` створює порожні файли. Докладніше її буде розглянуто в модулі 5.

**Крок 2. Застосуйте шаблони.**

```bash
printf '%s\n' *.txt
printf '%s\n' file?.*
printf '%s\n' report[12].txt
printf '%s\n' *[0-9].txt
printf '%s\n' *.md
```

**Крок 3. Порівняйте розгортання та буквальне значення.**

```bash
printf '%s\n' *.txt
printf '%s\n' "*.txt"
printf '%s\n' '*.txt'
```

**Крок 4. Перевірте шаблон, якому не відповідає жоден файл.**

```bash
printf '%s\n' *.pdf
```

Зафіксуйте результат і поясніть поведінку Bash.

**Крок 5. Застосуйте шаблон до системного каталогу.**

```bash
ls -d /etc/*.conf | head -n 5
cd ~
```

## Завдання 6. Перенаправлення та конвеєри

**Теорія:** модуль 4, розділи 8 і 9.

### Мета

Навчитися спрямовувати стандартні потоки у файли та будувати конвеєри з кількох команд.

### Порядок виконання

**Крок 1. Запишіть stdout у файл.**

```bash
ls /etc > ~/lab02/etc-list.txt
wc -l < ~/lab02/etc-list.txt
head -n 5 ~/lab02/etc-list.txt
```

**Крок 2. Порівняйте `>` і `>>`.**

```bash
printf 'Перший рядок\n' > ~/lab02/demo.txt
printf 'Другий рядок\n' >> ~/lab02/demo.txt
cat ~/lab02/demo.txt
printf 'Новий вміст\n' > ~/lab02/demo.txt
cat ~/lab02/demo.txt
```

Поясніть, що сталося з вмістом файла після останньої команди запису.

**Крок 3. Окремо перенаправте stdout і stderr.**

```bash
ls /etc /directory-that-does-not-exist > ~/lab02/out.txt 2> ~/lab02/err.txt
wc -l < ~/lab02/out.txt
cat ~/lab02/err.txt
```

**Крок 4. Об'єднайте потоки.**

```bash
ls /etc /directory-that-does-not-exist > ~/lab02/both.txt 2>&1
wc -l < ~/lab02/both.txt
tail -n 3 ~/lab02/both.txt
```

Порядок перенаправлень має значення: спершу stdout спрямовується у файл, потім stderr спрямовується туди, куди зараз спрямований stdout.

**Крок 5. Побудуйте конвеєри.**

```bash
ls /etc | sort | head -n 5
ls /etc | grep '^s' | wc -l
ls -l /usr | head -n 5
printenv | sort | head -n 5
```

**Крок 6. Об'єднайте конвеєр і перенаправлення.**

```bash
ls /etc | grep '^s' | sort > ~/lab02/etc-s.txt
cat ~/lab02/etc-s.txt
```

**Увага:** не перенаправляйте `stderr` у `/dev/null` без потреби: повідомлення про помилки потрібні для діагностики.
