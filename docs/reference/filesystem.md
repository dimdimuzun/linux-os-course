# Файлова система

Докладніше: [модуль 3](../modules/03-filesystem.md), [модуль 5](../modules/05-files-and-directories.md), [модуль 13](../modules/13-storage.md).

## Каталоги за FHS

| Каталог | Призначення |
|---|---|
| `/` | Корінь усієї ієрархії |
| `/bin`, `/sbin`, `/lib` | Основні програми й бібліотеки (в Ubuntu — посилання на `/usr/bin`, `/usr/sbin`, `/usr/lib`) |
| `/boot` | Ядро, початковий образ, файли завантажувача |
| `/dev` | Файли пристроїв (`/dev/null`, `/dev/sda`) |
| `/etc` | Конфігурація системи й служб |
| `/home` | Домашні каталоги користувачів |
| `/root` | Домашній каталог користувача `root` |
| `/media`, `/mnt` | Змінні носії; тимчасове ручне монтування |
| `/opt` | Додаткове ПЗ сторонніх постачальників |
| `/proc` | Віртуальна ФС: процеси й стан ядра |
| `/run` | Тимчасові дані поточного сеансу (`tmpfs`) |
| `/srv` | Дані служб (веб, FTP) |
| `/sys` | Віртуальна ФС: пристрої й драйвери |
| `/tmp` | Тимчасові файли (можуть очищатися) |
| `/usr` | Програми, бібліотеки, документація |
| `/var` | Змінні дані: журнали, кеші, черги |

### Підкаталоги

| Каталог | Призначення |
|---|---|
| `/usr/bin`, `/usr/sbin` | Виконувані файли для користувачів / адміністратора |
| `/usr/lib`, `/usr/share` | Бібліотеки; незалежні від архітектури дані й документація |
| `/usr/local` | Локально встановлене ПЗ (поза пакетним менеджером) |
| `/var/log` | Журнали |
| `/var/lib` | Стан програм і служб |
| `/var/cache` | Кеші |
| `/var/spool` | Черги |
| `/var/tmp` | Тимчасові файли, що зберігаються між перезавантаженнями |

## Де це шукати

| Що | Де |
|---|---|
| Конфігурація | `/etc` |
| Журнали | `/var/log`, `journalctl` |
| Файли користувача | `/home/<користувач>` |
| Виконуваний файл команди | `command -v ім'я` |
| Ядро | `/boot` |
| Інформація про процеси | `/proc` |
| Пристрої | `/dev`, `/sys` |
| Файли, що належать пакету | `dpkg -L пакет` |

## Шляхи

| Запис | Значення |
|---|---|
| `/etc/passwd` | Абсолютний шлях (від кореня) |
| `../etc`, `docs/a.txt` | Відносні шляхи (від поточного каталогу) |
| `.` / `..` | Поточний / батьківський каталог |
| `~` | Домашній каталог (розгортає оболонка) |
| `cd -` | Попередній каталог (`$OLDPWD`) |

```bash
realpath .
basename /var/log/syslog
dirname /var/log/syslog
```

Імена **чутливі до регістру**; імена, що починаються з `.`, приховані (`ls -a`). Значення з пробілами беріть у лапки.

## Типи об'єктів (перший символ `ls -l`)

| Символ | Тип |
|---|---|
| `-` | Звичайний файл |
| `d` | Каталог |
| `l` | Символічне посилання |
| `c` / `b` | Символьний / блоковий пристрій |
| `s` | Сокет |
| `p` | Іменований канал (FIFO) |

```bash
ls -ld /etc /dev/null
file /usr/bin/ls
stat file
```

## Посилання

| Властивість | Жорстке | Символічне |
|---|---|---|
| Що це | Ще одне ім'я того самого inode | Файл зі шляхом до цілі |
| Після видалення оригіналу | Дані зберігаються | Посилання стає «битим» |
| Між файловими системами | Ні | Так |
| Для каталогів | Зазвичай ні | Так |

```bash
ln original hard
ln -s original soft
readlink -f soft
find . -xtype l
ls -li
```

## Монтування й файлові системи

```bash
findmnt
findmnt -T ~
findmnt /
df -hT
lsblk -f
```

| Поняття | Значення |
|---|---|
| Точка монтування | Каталог, через який відкривається вміст файлової системи |
| `/proc`, `/sys`, `/dev`, `/run` | Віртуальні або тимчасові файлові системи |
| `squashfs`, `loop` | Snap-пакети й образи |
| `ext4`, `xfs`, `btrfs` | Файлові системи Linux із правами й власниками |
| `vfat`, `exfat`, `ntfs` | Не зберігають права Linux |

Перегляд змінюється командами `mount`/`umount` лише в навчальному середовищі та лише для власних образів (див. [сховище](storage.md)).

## Корисні команди

| Команда | Дія |
|---|---|
| `ls -ld шлях` | Відомості про об'єкт, а не про вміст |
| `df -h`, `df -i` | Місце й inode |
| `du -sh шлях` | Розмір каталогу |
| `find / -xdev -size +100M` | Великі файли в межах однієї ФС |
| `namei -l шлях` | Права на кожному каталозі шляху |
| `command -v ім'я` | Де розташована команда |
