# Команди Linux

Короткий довідник команд курсу. Докладні пояснення — у відповідних модулях; тематичні довідники: [файлова система](filesystem.md), [права доступу](permissions.md), [користувачі](users.md), [процеси](processes.md), [systemd](systemd.md), [мережі](networking.md), [сховище](storage.md), [Bash](bash.md).

## Довідка

```bash
man command
man 5 passwd
command --help
type command
command -v command
apropos слово
```

| Команда | Дія |
|---|---|
| `man команда` | Сторінка довідки (вихід — `q`, пошук — `/слово`) |
| `man N тема` | Довідка з конкретного розділу (`man 5 passwd`) |
| `команда --help` | Короткий опис параметрів |
| `type`, `command -v` | Що це за команда й де вона розташована |
| `apropos слово` | Пошук команд за описом |

## Навігація

```bash
pwd
ls
ls -la
ls -ld /etc
cd /path
cd ..
cd ~
cd -
```

| Запис | Значення |
|---|---|
| `.` / `..` | Поточний / батьківський каталог |
| `~` | Домашній каталог |
| `cd -` | Попередній каталог |
| `ls -l` | Докладний список |
| `ls -a` | З прихованими файлами |
| `ls -h` | Розміри в `K`, `M`, `G` |
| `ls -d` | Відомості про сам каталог, а не про вміст |

## Файли й каталоги

```bash
mkdir -p project/{docs,src}
touch file
cp source destination
cp -r dir1 dir2
mv source destination
rm file
rm -r dir
rmdir empty-dir
ln original hard
ln -s original soft
```

| Команда | Примітка |
|---|---|
| `mkdir -p` | Створює проміжні каталоги, не повертає помилку, якщо каталог існує |
| `cp -r`, `-i`, `-v`, `-a` | Копіювати каталоги / питати / докладно / зберегти метадані |
| `mv` | Перейменування й переміщення; без `-i` перезаписує мовчки |
| `rm -i`, `-r`, `-v` | Видалення **незворотне**: «кошика» немає |
| `ln -s` | Символічне посилання; відносна ціль відраховується від каталогу посилання |

## Перегляд вмісту й метаданих

```bash
cat file
less file
head -n 5 file
tail -n 5 file
tail -f logfile
wc -l file
file file
stat file
```

| Команда | Призначення |
|---|---|
| `cat -n` | Вивід із нумерацією рядків |
| `less` | Посторінковий перегляд: `Space`, `b`, `/пошук`, `n`, `g`, `G`, `q` |
| `wc -l -w -c` | Рядки, слова, байти |
| `file` | Тип за вмістом |
| `stat` | Розмір, inode, права, час змінення |

## Пошук і обробка тексту

```bash
find . -name '*.txt'
find . -type f -size +1M
find . -mtime -1
grep -rn "text" .
grep -i -v -c pattern file
cut -d: -f1,3 /etc/passwd
sort file | uniq -c | sort -rn
awk '{print $1}' file
```

| Команда | Призначення |
|---|---|
| `find шлях -name 'шаблон'` | Шаблон беріть у **лапки** |
| `find -type f/d/l`, `-size`, `-mtime`, `-mmin`, `-maxdepth` | Умови пошуку |
| `grep -i -v -c -n -r -E -o` | Регістр / виключити / кількість / номери / рекурсивно / регулярні вирази / лише збіг |
| `cut -d' ' -f1` | Вибір поля за роздільником |
| `sort`, `uniq -c` | Групування й підрахунок (`sort` перед `uniq` обов'язковий) |
| `awk '{print $N}'` | Поле N; `-F:` — роздільник |

## Архіви й копії

```bash
tar -czvf archive.tar.gz dir
tar -tzf archive.tar.gz
tar -xzvf archive.tar.gz -C dest
gzip -k file
sha256sum file
rsync -av src/ dest/
```

Перед розпакуванням переглядайте вміст (`tar -tzf`). `rsync -n` лише показує, що буде зроблено.

## Конвеєри та перенаправлення

| Запис | Дія |
|---|---|
| `команда > файл` | Записати stdout (перезапис) |
| `команда >> файл` | Додати stdout у кінець |
| `команда 2> файл` | Записати stderr |
| `команда > файл 2>&1` | stdout і stderr в один файл |
| `команда < файл` | Взяти stdin із файла |
| `a \| b` | stdout `a` стає stdin `b` |
| `a && b` / `a \|\| b` / `a ; b` | Якщо успіх / якщо помилка / незалежно |
| `$?` | Код завершення останньої команди |

## Змінні, лапки, шаблони

| Запис | Значення |
|---|---|
| `"$var"` | Підстановка змінної (подвійні лапки) |
| `'$var'` | Буквально, без підстановки |
| `*`, `?`, `[abc]` | Шаблони імен файлів |
| `{a,b,c}`, `{1..5}` | Розкриття фігурних дужок |
| `$(команда)` | Результат команди |
| `export VAR=...` | Змінна середовища (для дочірніх процесів) |

## Пакети (Ubuntu)

```bash
sudo apt update
apt list --upgradable
sudo apt upgrade
apt search --names-only '^tree$'
apt show tree
sudo apt install tree
sudo apt remove tree
sudo apt purge tree
sudo apt autoremove
apt -s install nginx
dpkg -l tree
dpkg -L tree
dpkg -S /usr/bin/ls
snap list
```

| Команда | Дія |
|---|---|
| `apt update` | Оновити **списки** пакетів (нічого не встановлює) |
| `apt upgrade` / `full-upgrade` | Оновити пакети |
| `remove` / `purge` | Видалити програму / разом із конфігурацією |
| `autoremove` | Видалити непотрібні залежності (спершу `apt -s autoremove`) |
| `apt -s …` | Симуляція без змін |
| `dpkg -L`, `dpkg -S` | Файли пакета; якому пакету належить файл |
| `apt-mark hold` | Зафіксувати версію |

## Небезпечні команди: перевіряйте перед виконанням

!!! danger

    - `rm -rf` — видалення без підтвердження; завжди перевіряйте `pwd` і шлях, не використовуйте з порожніми змінними (`"${dir:?}"`).
    - `chmod -R`, `chown -R` — зміна всього дерева; не застосовуйте до системних каталогів.
    - `mkfs`, `parted`, `dd` — знищують дані; перевіряйте пристрій (`lsblk -f`).
    - `sudo` — виконує команду з правами адміністратора; використовуйте лише за потреби.
    - `curl … | sudo bash` — виконує невідомий скрипт від `root`.
