## Шаблон скрипта

```bash
#!/usr/bin/env bash
# Призначення: коротко
# Використання: script.sh [-h] АРГУМЕНТ
set -euo pipefail

usage() {
  echo "Використання: ${0##*/} АРГУМЕНТ" >&2
}

main() {
  [[ $# -eq 1 ]] || { usage; exit 2; }
  local target="$1"
  [[ -d "$target" ]] || { echo "Не каталог: $target" >&2; exit 1; }
  echo "Обробка: $target"
}

main "$@"
```

Запуск: `chmod u+x script.sh && ./script.sh`; перевірка синтаксису — `bash -n`; трасування — `bash -x`.

## Параметри

| Змінна | Значення |
|---|---|
| `$0` | Ім'я скрипта |
| `$1`, `$2`, … | Аргументи |
| `$#` | Кількість аргументів |
| `"$@"` | Усі аргументи як окремі слова (**рекомендовано**) |
| `"$*"` | Усі аргументи одним рядком |
| `$?` | Код завершення останньої команди |
| `$$`, `$!` | PID скрипта; PID останнього фонового процесу |
| `shift` | Відкинути перший аргумент |

## Підстановка параметрів

| Запис | Дія |
|---|---|
| `${var:-x}` | Значення за замовчуванням |
| `${var:=x}` | Те саме й присвоїти |
| `${var:?повідомлення}` | Якщо порожня — повідомлення й вихід |
| `${#var}` | Довжина |
| `${var##*/}`, `${var%.*}` | Видалити префікс / суфікс (ім'я файла, розширення) |
| `${var/старе/нове}` | Замінити |
| `${var^^}`, `${var,,}` | Великі / малі літери |
| `$(( a + b ))` | Цілочислова арифметика |
| `$(команда)` | Результат команди |

## Умови

```bash
if [[ -d "$dir" ]]; then
  echo "каталог"
elif [[ -f "$dir" ]]; then
  echo "файл"
else
  echo "інше"
fi

case "$1" in
  start) echo "запуск" ;;
  stop|halt) echo "зупинка" ;;
  *.txt) echo "текст" ;;
  *) echo "невідомо" >&2; exit 2 ;;
esac
```

| Оператор | Істинно, якщо |
|---|---|
| `-e`, `-f`, `-d`, `-L` | Існує / файл / каталог / символічне посилання |
| `-r`, `-w`, `-x`, `-s` | Читання / запис / виконання / не порожній |
| `-z "$s"`, `-n "$s"` | Рядок порожній / не порожній |
| `"$a" == "$b"`, `!=` | Рядки збігаються / ні |
| `"$s" =~ ^[0-9]+$` | Регулярний вираз (лише `[[ ]]`) |
| `-eq`, `-ne`, `-lt`, `-le`, `-gt`, `-ge` | Числові порівняння |
| `!`, `&&`, `\|\|` | НЕ, І, АБО |

Пробіли навколо дужок і операторів **обов'язкові**. `A && B || C` — не те саме, що `if`: `C` виконається й тоді, коли `B` не вдалася.

## Цикли

```bash
for i in {1..5}; do echo "$i"; done
for ((i = 0; i < 3; i++)); do echo "$i"; done

for f in *.txt; do
  [[ -e "$f" ]] || continue
  echo "$f"
done

while IFS= read -r line; do
  echo "$line"
done < file

n=3
while [[ $n -gt 0 ]]; do n=$(( n - 1 )); done
until [[ $n -ge 3 ]]; do n=$(( n + 1 )); done
```

`break` — вийти з циклу, `continue` — наступна ітерація. Обходьте файли **шаблонами**, а не `$(ls)`.

## Функції й масиви

```bash
is_number() { [[ "$1" =~ ^[0-9]+$ ]]; }

max() {
  local a="$1" b="$2"
  if (( a > b )); then echo "$a"; else echo "$b"; fi
}
biggest="$(max 7 12)"

arr=(a b c)
arr+=(d)
echo "${arr[0]}" "${#arr[@]}"
for x in "${arr[@]}"; do echo "$x"; done
mapfile -t files < <(ls -1t -- *.txt 2>/dev/null)
```

- `return N` повертає **код** (0–255); значення повертають **виводом** і зчитують через `$(…)`;
- `local` робить змінні локальними;
- `"${arr[@]}"` обходить елементи без втрати меж.

## Коди завершення та помилки

| Код | Значення |
|---:|---|
| `0` | Успіх |
| `1` | Загальна помилка |
| `2` | Неправильне використання |
| `126` | Не можна виконати (немає `x`) |
| `127` | Команду не знайдено |
| `128+N` | Завершено сигналом N (`130` — `Ctrl+C`, `143` — `SIGTERM`) |

```bash
cd "$dir" || { echo "Не вдалося перейти" >&2; exit 1; }
tar -czf "$archive" "$src" || exit 1
```

Повідомлення про помилки — у `stderr`: `echo "помилка" >&2`.

| `set` | Дія |
|---|---|
| `-e` | Завершити за помилки команди (не діє в умовах `if`, лівих частинах `&&`/`\|\|`) |
| `-u` | Незадана змінна — помилка |
| `-o pipefail` | Помилка будь-якої частини конвеєра |

Пастки: `(( n++ ))` при `n=0` повертає `1`; `grep` без збігів повертає `1`.

## `trap`, `mktemp`, `getopts`

```bash
tmp="$(mktemp -d)"
cleanup() { rm -rf -- "$tmp"; }
trap cleanup EXIT

verbose=0
while getopts ":vk:h" opt; do
  case "$opt" in
    v) verbose=1 ;;
    k) keep="$OPTARG" ;;
    h) usage; exit 0 ;;
    \?) echo "Невідома опція: -$OPTARG" >&2; usage; exit 2 ;;
    :) echo "Опція -$OPTARG потребує значення" >&2; usage; exit 2 ;;
  esac
done
shift $(( OPTIND - 1 ))
```

`trap … EXIT` спрацьовує завжди; події: `EXIT`, `INT`, `TERM`, `ERR`. `mktemp` створює унікальний файл/каталог із безпечними правами.

## Безпека скриптів

1. Беріть змінні в подвійні лапки: `"$var"`, `"$@"`.
2. Перевіряйте введення: кількість аргументів, існування шляху, формат числа.
3. Захищайте видалення: `rm -rf -- "${dir:?}"/*`.
4. Не використовуйте `eval` із недовіреними даними.
5. Тимчасові файли — лише через `mktemp`.
6. Не передавайте паролі аргументами й не зберігайте їх у скриптах (аргументи видно в `ps`).
7. Привілейовані скрипти мають належати `root` і не бути доступними для запису іншим.
8. Читайте чужі скрипти перед запуском з `sudo`.
