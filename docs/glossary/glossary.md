# Глосарій

Терміни подано в алфавітному порядку. У дужках після терміна — українські відповідники й скорочення; у кінці значення — номер модуля, де тему розглянуто докладніше.

| Термін | Значення |
|---|---|
| Absolute path (абсолютний шлях) | Шлях, що починається з `/` і відраховується від кореня (модуль 3) |
| ACL (Access Control List) | Розширений список прав доступу до об'єкта, окрім класичних `rwx`; наявність позначається `+` у `ls -l` (модуль 6) |
| Alias | Короткий псевдонім для довшої команди в оболонці (модуль 4) |
| AppArmor | Система мандатного контролю доступу в Ubuntu: обмежує можливості програм за профілями (модуль 15) |
| apt | Високорівневий менеджер пакетів Debian/Ubuntu; працює з репозиторіями (модуль 9) |
| Argument (аргумент) | Значення, яке передається команді після її імені (модуль 4) |
| ARP | Протокол визначення MAC-адреси за IPv4-адресою в локальній мережі (модуль 11) |
| Array (масив) | Змінна Bash, що містить список значень (модуль 14) |
| Attack surface (поверхня атаки) | Усі точки, через які систему можна атакувати: служби, порти, облікові записи, пакети (модуль 15) |
| Bash | Bourne Again Shell: найпоширеніша оболонка Linux (модулі 4, 14) |
| Block device (блоковий пристрій) | Пристрій, дані якого читаються блоками: диски, розділи, loop-пристрої (модуль 13) |
| Boot loader (завантажувач) | Програма (GRUB), яка завантажує ядро в пам'ять (модуль 10) |
| Brace expansion | Розкриття фігурних дужок оболонкою: `{a,b}`, `{1..5}` (модуль 5) |
| Broadcast address | Адреса, на яку надсилається пакет усім вузлам підмережі (модуль 11) |
| Brute force (підбір паролів) | Атака перебором облікових даних; ознака — безліч `Failed password` (модуль 15) |
| cgroup | Механізм ядра, що об'єднує процеси в групи для обліку й обмеження ресурсів; `systemd` використовує його для служб (модуль 10) |
| chmod | Команда зміни прав доступу (модуль 6) |
| CIDR | Запис мережі з префіксом: `192.168.1.0/24` (модуль 11) |
| Command substitution | Підстановка результату команди: `$(команда)` (модуль 4) |
| Conffile | Файл конфігурації пакета, який може змінювати адміністратор; зберігається після `apt remove` (модуль 9) |
| cron | Служба планування виконання команд за розкладом; налаштовується `crontab` (модуль 14) |
| Daemon (демон) | Фоновий процес-служба без прив'язки до терміналу (модуль 10) |
| Default gateway (шлюз за замовчуванням) | Маршрутизатор, на який надсилаються пакети для зовнішніх мереж (модуль 11) |
| Defense in depth (багаторівневий захист) | Принцип: кілька незалежних бар'єрів захисту замість одного (модуль 15) |
| Dependency (залежність) | Пакет або юніт, без якого інший не працюватиме (модулі 9, 10) |
| DHCP | Протокол автоматичного надання адреси, шлюзу й DNS-серверів (модуль 11) |
| Distribution (дистрибутив) | Збірка Linux: ядро, пакети, інсталятор, менеджер пакетів (Ubuntu, Debian, Fedora) (модуль 1) |
| DNS | Система перетворення імен на IP-адреси (модуль 11) |
| dpkg | Низькорівневий менеджер `.deb`-пакетів і база встановлених пакетів (модуль 9) |
| Drop-in | Додатковий файл налаштувань юніта в `імя.service.d/`, що змінює окремі параметри (модуль 10) |
| Environment variable (змінна середовища) | Змінна, експортована дочірнім процесам (`export`) (модуль 4) |
| Exit code (код завершення) | Число, яке повертає процес: `0` — успіх, інше — помилка; `$?` (модуль 4) |
| ext4 | Типова журнальна файлова система Linux (модуль 13) |
| Facility (категорія) | Тип джерела повідомлення системного журналу: `auth`, `kern`, `daemon` (модуль 15) |
| FHS | Filesystem Hierarchy Standard: стандарт структури каталогів Linux (модуль 3) |
| File descriptor (дескриптор файла) | Число, що позначає відкритий файл або потік процесу: 0 — stdin, 1 — stdout, 2 — stderr (модулі 4, 8) |
| Filesystem (файлова система) | Структура зберігання файлів на розділі або загальна ієрархія каталогів (модуль 3) |
| Firewall (брандмауер) | Засіб фільтрації мережевих пакетів за правилами (`ufw`, `nftables`) (модуль 15) |
| Foreground / Background | Передній план (оболонка чекає завершення) / фон (`&`) (модуль 8) |
| fstab | Файл `/etc/fstab`: постійне монтування файлових систем під час завантаження (модуль 13) |
| Function (функція) | Іменований блок команд у скрипті (модуль 14) |
| GID | Числовий ідентифікатор групи (модуль 7) |
| Glob (шаблон) | Шаблони імен файлів `*`, `?`, `[...]`, які розгортає оболонка (модуль 4) |
| GPT | Сучасна таблиця розділів диска (модуль 13) |
| Group (група) | Набір користувачів для спільного керування доступом (модуль 7) |
| GRUB | Типовий завантажувач Linux (модулі 10, 16) |
| Hard link (жорстке посилання) | Ще одне ім'я того самого inode (модуль 5) |
| Hardening | Посилення захисту системи: вимкнення зайвого, обмеження прав, оновлення (модуль 15) |
| Home directory (домашній каталог) | Особистий каталог користувача; `~` (модулі 3, 7) |
| Hostname | Ім'я вузла в мережі (`hostnamectl`) (модуль 11) |
| Inode | Запис файлової системи з метаданими файла; кількість обмежена (модулі 5, 13) |
| Interface (інтерфейс) | Точка підключення вузла до мережі (`enp0s3`, `lo`) (модуль 11) |
| IP address (IP-адреса) | Адреса вузла в мережі (IPv4 — 32 біти, IPv6 — 128 бітів) (модуль 11) |
| Journal / journald | Двійковий системний журнал `systemd` і його служба; читається `journalctl` (модулі 10, 15) |
| Kernel (ядро) | Ядро операційної системи: керує пам'яттю, процесами, пристроями (модуль 1) |
| Least privilege (мінімальні привілеї) | Принцип: кожен отримує лише необхідні права (модулі 6, 7, 15) |
| Load average | Середня кількість процесів, що виконуються або очікують процесор, за 1, 5 та 15 хвилин (модуль 8) |
| Log (журнал) | Запис подій системи й програм (модуль 15) |
| logrotate | Інструмент ротації журналів: перейменування, стиснення, видалення старих (модуль 15) |
| Loop device (loop-пристрій) | Файл, підключений як блоковий пристрій (`/dev/loopN`); безпечний засіб навчання (модуль 13) |
| Loopback | Інтерфейс `lo` і адреса `127.0.0.1`: зв'язок вузла із самим собою (модуль 11) |
| LUKS | Стандарт шифрування розділів Linux (`cryptsetup`) (модуль 13) |
| LVM | Менеджер логічних томів: PV, VG, LV (модуль 13) |
| MAC address (MAC-адреса) | 48-бітна адреса мережевої плати в локальній мережі (модуль 11) |
| MBR | Класична таблиця розділів: до 2 ТіБ, 4 основні розділи (модуль 13) |
| Mount point (точка монтування) | Каталог, у якому доступна змонтована файлова система (модулі 3, 13) |
| MTU | Максимальний розмір кадру в мережі; для Ethernet — 1500 байтів (модуль 11) |
| NAT | Трансляція адрес: вузли з приватними адресами виходять в Інтернет через одну публічну (модуль 11) |
| Netplan | Інструмент постійної мережевої конфігурації Ubuntu (YAML у `/etc/netplan`) (модуль 11) |
| nice | Значення пріоритету процесу від −20 до 19 (модуль 8) |
| nologin | Оболонка, що забороняє інтерактивний вхід; для службових облікових записів (модуль 7) |
| NSS | Механізм вибору джерел імен та облікових записів за `/etc/nsswitch.conf` (модуль 11) |
| OOM killer | Механізм ядра, що завершує процеси за нестачі пам'яті (модуль 16) |
| Option (параметр, опція) | Прапорець, що змінює поведінку команди: `-l`, `--help` (модуль 4) |
| Orphan (сирота) | Процес, батько якого завершився; його усиновлює `systemd` (модуль 8) |
| Package (пакет) | Архів із програмою, залежностями й метаданими (`.deb`) (модуль 9) |
| Partition (розділ) | Виділена частина диска (модуль 13) |
| PATH | Змінна зі списком каталогів, де оболонка шукає команди (модуль 4) |
| Permission (право доступу) | Право на читання, запис, виконання об'єкта (модуль 6) |
| PID / PPID | Ідентифікатор процесу / його батьківського процесу (модуль 8) |
| Pipe (конвеєр) | Передавання stdout однієї команди на stdin іншої: `a \| b` (модуль 4) |
| Port (порт) | Номер, що позначає програму на вузлі (0–65535) (модулі 11, 12) |
| Post-mortem | Звіт про інцидент: хронологія, причина, виправлення, профілактика (модуль 16) |
| PPA | Персональний архів пакетів Ubuntu; сторонній репозиторій, довіряти якому слід обережно (модуль 9) |
| Prefix (префікс) | Кількість бітів мережевої частини адреси (`/24`) (модуль 11) |
| Privilege escalation | Підвищення привілеїв; легальне (`sudo`) або в результаті атаки (модулі 7, 15) |
| Process (процес) | Виконуваний екземпляр програми (модуль 8) |
| RAID | Об'єднання дисків для надійності чи швидкості; не замінює резервну копію (модуль 13) |
| Redirection (перенаправлення) | Спрямування потоків у файл або з файла: `>`, `>>`, `<`, `2>` (модуль 4) |
| Relative path (відносний шлях) | Шлях від поточного каталогу (модуль 3) |
| Repository (репозиторій) | Джерело пакетів програмного забезпечення (модуль 9) |
| Root | Суперкористувач із UID 0; а також кореневий каталог `/` (модулі 3, 7) |
| Routing table (таблиця маршрутизації) | Перелік маршрутів для вибору шляху пакетів (`ip route`) (модуль 11) |
| Service (служба) | Фоновий процес, яким керує `systemd` (модуль 10) |
| Severity (рівень важливості) | Пріоритет повідомлення журналу: `emerg` … `debug` (модуль 15) |
| Shebang | Перший рядок скрипта `#!/bin/bash` із вказівкою інтерпретатора (модуль 14) |
| Shell (оболонка) | Інтерфейс взаємодії користувача з ОС (модуль 4) |
| Signal (сигнал) | Повідомлення процесу: `SIGTERM`, `SIGKILL`, `SIGHUP` (модуль 8) |
| Snap | Формат пакетів Canonical із власними залежностями й пісочницею (модуль 9) |
| Snapshot (знімок) | Збережений стан віртуальної машини для швидкого відновлення (модуль 2) |
| Socket (сокет) | Комбінація адреси, порту й протоколу; кінцева точка мережевого з'єднання (модуль 11) |
| Sparse file (розріджений файл) | Файл, що займає на диску лише записані блоки (модуль 13) |
| SSH | Захищений протокол віддаленого доступу (модулі 2, 12) |
| stdin / stdout / stderr | Стандартні потоки: введення, виведення, помилок (модуль 4) |
| Sticky bit | Біт каталогу: видаляти можна лише власні об'єкти (`/tmp`) (модуль 6) |
| sudo | Виконання команди від імені іншого користувача, зазвичай `root` (модуль 7) |
| SUID / SGID | Біти, за яких програма працює з правами власника / групи файла (модуль 6) |
| Superuser | Користувач із необмеженими правами (`root`) (модуль 7) |
| Swap | Область підкачки: місце на диску для сторінок пам'яті (модуль 13) |
| Symbolic link (символічне посилання) | Файл зі шляхом до іншого об'єкта (модулі 3, 5) |

| Target (ціль) | Група юнітів `systemd`, що визначає стан системи (`multi-user.target`) (модуль 10) |
| TCP | Протокол надійної передачі з установленням з'єднання (модуль 11) |
| Terminal (термінал) | Програма, що надає вікно для введення команд; відрізняється від оболонки (модуль 4) |
| Timer (таймер) | Юніт `systemd`, що запускає службу за розкладом (модуль 10) |

| UID | Числовий ідентифікатор користувача (модуль 7) |

| Variable (змінна) | Іменоване значення в оболонці (модуль 4) |
