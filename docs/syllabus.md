# Силабус

## Назва

**Операційні системи — Основи Linux**

## Мета

Надати студентам системне розуміння основ операційних систем на прикладі Linux та сформувати практичні навички роботи з командним рядком.

## Тематичні блоки

| Блок | Модулі |
|---|---|
| Основи Linux | 1–4 |
| Файли та доступ | 5–6 |
| Користувачі та процеси | 7–8 |
| ПЗ та служби | 9–10 |
| Мережі | 11–12 |
| Сховища та автоматизація | 13–14 |
| Логи, безпека та діагностика | 15–16 |

## Практична частина

8 лабораторних робіт об'єднують по два тематично близькі модулі.

## Контроль

- лабораторні роботи — практичні навички;
- Квіз 1 — модулі 1–8;
- Квіз 2 — модулі 9–16;
- підсумкове оцінювання — відповідно до правил дисципліни в Moodle.
